# AI Personal Portfolio

React + Tailwind CSS hero section for a personal portfolio.

```bash
npm install
npm run dev
```

- Hero component: `src/components/Hero.jsx`
- Brush-stroke image mask: `public/brush-mask.svg` (applied via `.brush-mask` in `src/index.css`)
- Swap the portrait by changing `PORTRAIT` in `Hero.jsx` (or drop a file in `public/` and point to it).
